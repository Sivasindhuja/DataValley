# Account Policy v3

- Customers must verify identity via verify_customer before account changes.
- Sensitive actions (email/phone/password change) require OTP verification and are high-risk.
- Login troubleshooting: check credentials, reset via verified email, check account status.
- Communication preference can be updated via medium-risk tool.
